# Foodpilot

A modern open-source platform for restaurant ordering, delivery management and takeaway services.

## Vision

Foodpilot aims to provide restaurants and takeaway businesses with a modern, self-hostable ordering and delivery platform.

The MVP focuses on a standalone ordering interface that can be linked from an existing restaurant website through a simple call-to-action button.

Foodpilot is not intended to be a full restaurant website builder.

## Core Features

- Online ordering
- Order management
- Delivery management
- Customer management
- Multiple locations
- Open API
- Self-hostable
- Standalone ordering interface
- Simple integration into existing restaurant websites
